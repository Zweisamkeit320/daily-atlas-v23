# 医学插图素材

本目录包含 24 张本地原创概念插图，服务于 500 条一般医学科普。它们按主题复用，用来帮助识别内容层级，不展示个体检查结果，也不承担诊断或治疗建议。

`manifest.json` 是运行时与打包时的唯一清单。每项记录稳定 `key`、WebP 路径、医学主题组、视觉主题和忠实替代文本；构建会拒绝缺图、重复 key、额外未登记 WebP 或目录未实际引用的图片。500 条医学内容中的 `illustrationKey` 必须全部落在这 24 项中，每张图当前对应 5–40 条内容。

| 营养、消化与口腔 | 营养补水；口腔与消化 |
| 心血管、代谢与肾脏 | 心血管监测；代谢与肾脏 |
| 感染预防与免疫 | 疫苗免疫；手卫生与感染预防 |
| 心理、脑健康与成瘾 | 心理支持；脑健康与成瘾支持 |
| 感官与皮肤 | 视觉听觉；皮肤与日晒防护 |
| 用药、检查与健康素养 | 用药核对；检查与健康信息理解 |
| 急救与紧急警示 | 心肺复苏与 AED；气道、创伤与求助 |

## 创作与文件边界

- `medical-themes-sprite.png` 是 2026-08-11 使用 OpenAI 内置图像生成工具生成的六宫格母图；`sleep.webp`、`activity.webp`、`nutrition.webp`、`immunity.webp`、`brain.webp`、`emergency.webp` 由该母图裁切。
- 其余 18 张插图于 2026-08-28 使用同一内置图像生成能力逐主题生成，再转换为 768×768 WebP。它们沿用象牙白、深青、鼠尾草绿和陶土红的编辑插画体系。
- 图片不含第三方照片、品牌、水印、药品商品名或可被误解为真实检查结果的文字。
- 图像生成与 WebP 编码不声明跨次运行字节确定；正式交付哈希以实际随包文件重新计算。

原六图的裁切命令仍可用于检查母图和对应 WebP：

```powershell
python -m pip install -r requirements-assets.txt
python scripts/crop-medical-sprite.py
```

24 张 WebP、`manifest.json` 与本说明均进入 PWA 轻量应用壳，因此医学主题视觉在离线状态下仍可用。医学事实、行动建议、警示症状与来源边界以卡片文字和所链接的公共卫生／医疗机构页面为准。
