# Visual assets

This directory contains the compact browser manifest and is reserved for assets whose local redistribution boundary is recorded explicitly in `data/visuals/visual-manifest.v1.json`.

Book covers and movie posters must not be bulk-copied here: the v2.4 manifest classifies them as remote-only references with item-level rights not established. City WebP files may be added only after the Commons override validator accepts their file-level licence, attribution, subject review and SHA-256 metadata.
