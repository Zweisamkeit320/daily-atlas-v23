# Reviewed city WebP outputs

Expected file names are stable and derived only from a validated city ID:

```text
assets/visuals/cities/city-paris.webp
```

Do not place an image here based only on a search-result thumbnail. Before conversion, record the Wikimedia Commons file page, original and thumbnail URLs, author, attribution, allow-listed licence, metadata retrieval time and SHA-256, and a city-subject review in `data/visuals/city-commons-overrides.json`. The generated manifest then records the output path, dimensions and WebP SHA-256.
