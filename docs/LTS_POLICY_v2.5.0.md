# 今日万象 v2.5.0 LTS 最终功能版与维护规则

生效日期：2026-09-02  
状态：`FEATURE_FINAL / MAINTENANCE_ONLY_AFTER_RELEASE`

## “最终版”的可验证含义

v2.5.0 是今日万象每日五项推荐功能的最终功能基线。它不承诺互联网、第三方服务、未来浏览器或所有设备永远不会变化，也不使用“绝对无错误”作为无法检验的验收条件。它承诺的是：v2.5.0 发布后不再以扩充功能、扩大候选池或改变产品定位为目标持续升级。

以下合同冻结：

- 每日五项：图书、电影、城市、德语、医学；
- 内容规模：500 本图书、500 部电影、200 座城市、500 条德语、500 条医学科普；
- 书影题材：历史、悬疑、科幻；
- 本地优先、无账号、无后端、无行为分析；
- 喜欢、不适合、收藏、偏好、探索记录、JSON 备份和轻量／完整离线；
- 随包 500 个德语固定女声音频、24 张医学主题图、200 张开放许可城市图；
- 当前存储键、备份 schema、随机推荐策略和两个生产 Origin 的数据隔离边界。

## 发布后的允许改动

只有以下情况可以产生 v2.5.x 维护补丁：

1. 能稳定复现的页面打不开、数据丢失、更新循环、图文串项、离线失败、音频失败或布局阻断；
2. 安全漏洞、依赖安全修复或浏览器平台变化导致的兼容性故障；
3. 来源、许可、署名或隐私说明出现必须纠正的事实与合规问题；
4. 医学、德语、书影或城市内容发现明确事实错误、危险表达或来源失效；
5. 可访问性回归使键盘、读屏、对比度、缩放或减少动画路径不可用。

维护补丁只修复已识别问题，不顺带增加功能。第三方书封、电影海报、设备语音后备、天气或固定 CDN 的偶发不可用，在同源核心功能和本地回退正常时不单独触发版本。

## 不再进入主线的升级

- 不继续增加书、电影、城市、德语、医学或音乐数量；
- 不增加账号、云同步、广告、行为追踪、社交排行或个体化医疗建议；
- 不为追求设备清单形式完整而伪造没有设备的真机结果；
- 不因“还能再优化”就重做已稳定的界面、推荐算法或存储架构；
- 不在未获书面许可时加入豆瓣数据或把书封、海报批量复制为同源素材。

## 维护证据

每个实际发布的 v2.5.x 版本至少保留：

- 精确源码提交、版本标签、完整审计 ZIP 和静态部署 ZIP；
- ZIP SHA-256、整树清单与干净解压复验；
- 单元测试、Chromium／Firefox／WebKit、双基址、弱网、离线和 WCAG 结果；
- 独立严格审查者的六维只读复核；
- 同一 Origin 的 A→B 用户数据保留证据；
- 能执行的实体 Android 浏览器／网络结果，缺少的设备明确记为 `BLOCKED`。

维护是尽力而为，不承诺固定服务等级或第三方网络可达性。遇到异常时先保存浏览器版本、网络、完整网址、诊断摘要和截图，不先清除站点数据；跨 Origin 或跨浏览器迁移使用应用内 JSON 导出与导入。
