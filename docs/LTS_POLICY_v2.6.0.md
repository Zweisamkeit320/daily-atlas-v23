# 今日万象 v2.6.0 LTS Visual Edition 冻结策略

v2.6.0 是在 v2.5.0 最终功能版之上，经用户明确授权增加原创本地主题插画后的视觉功能基线。它保留 v2.5.0 的推荐内容、稳定 ID、用户数据和离线包，并把视觉策略明确为“原书封／海报优先，原创本地插画回退”。

## 冻结范围

- 内容池固定为图书 500、电影 500、城市 200、德语 500、医学 500、轻音乐 100，不继续增加书、电影、城市、德语、医学或音乐数量。
- 图书与电影均由现有本地代码根据作品类型、题材和稳定 ID 生成原创 SVG 主题插画；不复制或模仿原封面、原海报、人物肖像、Logo 或具体宣传构图。
- 默认仅联网加载白名单原书封／海报，成功解码后覆盖插画；图片缺失、失败、离线、数据节省或显式安全模式均保留插画。第三方图片不进入发布包、应用 Cache 或完整离线包。
- 插画不嵌入作品标题，不包含外部 URL、位图、脚本或事件处理器。
- 推荐算法、题材分类、评分与来源口径、候选项顺序和用户偏好算法不因插画改变。
- `dailyAtlas.profile.v1`、`dailyAtlas.state.v3.*`、备份 schema 1 和既有可选设置键保持兼容，同 Origin 更新不得清除收藏、偏好或离线模式。
- 城市开放许可图片、24 张医学主题图、500 条德语朗读和完整离线清单继续沿用既有契约。

## 允许的后续维护

冻结后仅接受可复现的核心故障、安全／兼容性问题、来源许可变化、医学安全问题、可访问性阻断，或插画导致的明确图文错配、溢出、不可见和显著性能回退。单纯更换风格、追求更多变体或继续扩池不构成维护版本理由。

## 发布边界

候选包、桌面自动化和模拟移动 User-Agent 不能替代实体夸克、vivo、微信或其他手机浏览器证据。正式部署需要先通过源码与干净解压测试，再经用户单独确认部署；部署后保留 v2.5.0 → v2.6.0 同 Origin 的收藏、偏好、轻量离线和断网重开证据。
