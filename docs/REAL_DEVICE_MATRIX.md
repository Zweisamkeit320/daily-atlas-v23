### B 手机失败与回退

- 用户报告 B 发布后：夸克无法打开首页和诊断页；vivo 浏览器在 Wi-Fi 下最初可打开，关闭后再次进入无法打开；移动数据均无法打开；首次打开时未看到原收藏，其余项目因不可达无法继续检测。
- 执行机随后在实际 Pages 部署上复现：新上下文首次加载正常，Service Worker 约 22 秒后激活，之后刷新稳定出现 `net::ERR_FAILED`。根因是 Pages 把 `/index.html` 以同源 308 规范化到 `/`，旧 Worker 缓存了带重定向历史的 Response，并把它作为导航回退返回；Chromium 拒绝这种缓存导航响应。服务器端 HTTP 200 与逐字节哈希检查无法覆盖这一浏览器运行时故障。
- 未清除手机站点数据。2026-08-29 已把同一生产 Origin 可逆回退到冻结 A=`v2.3.0-r5`，新部署 ID `a2d504f2-2f3e-4f4c-a7e8-8d580285de84`；在线诊断页显示 `v2.3.0`，在线 `sw.js` SHA-256 与冻结 A 一致。B 部署保留在 Cloudflare 历史中，但不再是 Production。
- 回退 A 后，用户确认夸克和 vivo 均可打开，并且两浏览器中的收藏、偏好和轻量离线在重新打开后保留。因此没有发生服务端删除或 B 导入覆盖；“收藏消失”是应用页未能启动时的表象。`r3` 不得再次部署，修复只能以新版本 `r4` 重新走非生产升级验收。

允许的最终状态：

- `PASS`：该网络格的核心功能全部通过，证据齐全；
- `FAIL`：站点已经收到请求，但功能结果不符合通过标准；
- `PARTIAL — PLATFORM UNSUPPORTED`：浏览、搜索等核心路径通过，但该浏览器确实不提供安装、Service Worker、Web Crypto 或其他指定平台能力；必须记录实际提示和可行替代路径；
- `BLOCKED — NETWORK`：在页面收到任何 HTTP 响应前超时、DNS 失败、TLS 被拦截或运营商不可达；不能记为应用代码失败，也不能记为通过；
- `NOT RUN — 需实体设备`：尚未在该实体设备和真实网络上执行。

## 每格开始前

1. 记录设备型号、系统版本、浏览器／微信精确版本、测试 URL、时间、所在地区、网络名称或运营商；关闭代理与 VPN，除非本轮专门测试代理场景。
2. 先打开同源 `diagnostics.html`，复制诊断摘要并记录总体状态、关键文件耗时、可用存储、Service Worker 状态和错误码；诊断摘要不替代后续功能实测。
3. 确认 URL 为全新发布的 `https://` 地址，浏览器没有证书警告。若从旧域名迁移，先在旧源导出备份；浏览器的收藏、偏好、Cache 和安装状态不会跨 Origin 自动迁移。
4. Wi-Fi 格必须连接真实 Wi-Fi；移动数据格必须关闭 Wi-Fi，并在状态栏确认蜂窝网络图标。开发者工具中的 Offline／Slow 4G 不算移动数据。
5. 使用新的浏览器资料或先记录并导出该测试源的数据。不要在未备份时清除真实用户的站点数据。
6. 测试离线前先完成相应的轻量或完整下载；随后打开飞行模式并确认 Wi-Fi 与蜂窝数据都已关闭。仅拔掉电脑网线不算手机离线。

## 每格执行步骤与通过标准

### 1. HTTPS、首屏与五张卡

1. 从地址栏直接打开测试 URL，不从桌面已缓存页面进入。
2. 等待首屏稳定，刷新一次，再退出浏览器并重新打开一次。
3. 使用手机底部快速导航依次跳到图书、电影、城市、德语、医学。

通过标准：无证书警告和白屏；页头、日期、今日主题出现；五张卡均有标题与正文；医学卡显示本地插图和一般科普边界；底部五项导航不会遮住操作按钮，横向无必须拖动的页面溢出。

### 2. 全库搜索与探索

1. 打开“探索 2,200 项”，确认总量文案为 2,200。
2. 分别筛选书／电影、城市地区、德语等级和医学主题；至少执行一次书影年代或评分筛选。
3. 输入一个中文词、一个英文词和一个德语词，翻到下一页后返回上一页。
4. 从结果打开一个系列书影条目，核对系列名、卷次或前置阅读／观看提示；没有系列的条目不应伪造卷次。

通过标准：筛选和分页有响应，无整页冻结、重复点击或明显错位；结果卡可读，清空条件后能恢复；空结果有明确提示而不是无限加载。

### 3. 声音必须由手势触发

1. 页面首次打开后等待 10 秒，确认没有自动播放背景音乐或朗读。
2. 点击背景音乐播放，调节音量，暂停后再播放。
3. 点击当前德语卡的女生朗读按钮，播放结束后再点一次。
4. 可选故障验证：在未缓存当前音频时断网点击，记录固定 MP3 和设备 Web Speech 的真实降级提示。

通过标准：没有自动发声；用户点击后音乐和固定朗读可以播放，朗读时音乐自动压低并在结束后恢复；若浏览器缺少音频／Web Speech 能力，页面清除活动播放状态并诚实显示失败或不可用，不能继续显示“正在播放”或把未知系统声音称为固定女声。

### 4. 默认轻量离线

1. 在在线状态打开离线设置，确认默认选中“轻量离线”。
2. 不点击完整下载，播放一次当前德语朗读，使当前 MP3 进入按需缓存。
3. 切换飞行模式，彻底关闭再重开页面或主屏入口；核对今日五张已访问卡与当前德语朗读。若在线阶段已执行过搜索，可额外记录该已访问搜索是否命中缓存，但轻量模式不承诺完整 2,200 项离线搜索。
4. 恢复网络后确认没有出现 500 条朗读的完整下载完成标记。

通过标准：首次安装不预取 44 个详情分片、搜索索引或 500 个 MP3；应用壳、2,200 项紧凑选择索引、今日已访问详情、24 张医学图和当前已播放的德语朗读在离线时可用。未访问详情与全库搜索允许提示需要联网或完整离线；远程封面、海报、天气和外部来源允许不可用，但必须使用本地视觉或明确提示。若浏览器不支持 Service Worker，记录 `PLATFORM UNSUPPORTED`，不能宣称已离线。

### 5. 用户主动选择完整离线

1. 恢复稳定网络，明确点击“完整离线”。
2. 观察进度出现；下载一段后点击“暂停”，记录已完成数量，关闭并重开页面，再点“继续下载”，确认只补缺项且进度不归零。
3. 再做一次“取消”，确认可选暂存被删除而轻量内容仍可用；重新选择完整离线。
4. 等待界面显示完成；记录总耗时、网络、估算空间、浏览器配额和持久存储结果。
5. 开启飞行模式，重新打开页面；执行一个此前未访问过的全库搜索，打开多个此前未访问的详情，并播放清单中的第一条、当前条和第 500 条德语 MP3。

通过标准：只有显式操作才下载完整包；进度可见，暂停／刷新／继续能保留并复核已完成项，取消会删除可选暂存；44 个详情分片、搜索索引和全部 500 个音频均经校验后才显示完成。离线时可搜索并打开未访问详情，也能播放抽测的首／中／末音频。网络、配额或单文件失败时不得写入虚假完成标记，已验证暂存可以继续，轻量应用壳仍可打开。

### 6. 加密备份、差异预览与恢复模式

使用专门的测试记录，不要拿唯一真实数据直接做覆盖实验。

1. 先收藏一个项目、喜欢另一个项目并标记一项已了解；导出一份明文备份作为回退。
2. 设置一次性测试密码，导出加密备份；确认页面不会记住或回显密码。
3. 导入该文件并输入错误密码，确认无法进入预览且任何记录均未改变。
4. 输入正确密码，核对恢复前差异预览；先关闭／取消预览，再确认数据零写入。
5. 在可丢弃测试数据上分别验证“合并”和“替换”：合并应保留本机当前卡并合并长期已了解；替换应按备份恢复并删除备份省略的可选白名单键。
6. 关闭并重开页面，确认最终选择的结果仍在；最后用第 1 步明文备份恢复测试基线。

通过标准：错误密码、篡改文件和取消预览均为零写入；正确密码只解锁差异预览；合并／替换语义与预览一致；没有密码上传或持久化。若浏览器不支持 Web Crypto，应明确提示只能使用明文备份，并把加密子项记为 `PLATFORM UNSUPPORTED`。

### 7. 公开安全素材、周报与医学插图

1. 打开设置，确认数据节省开关已勾选且不可关闭，帮助文案显示“公开安全素材模式已固定启用”；刷新后浏览主卡和搜索结果中的书／电影。
2. 新增数条探索、喜欢或收藏记录，打开“本周回顾”。
3. 在搜索中切换多个医学主题，抽看至少三张不同主题插图，并打开医学图清单核对共 24 张。

通过标准：页面和诊断摘要都显示公开安全素材模式，浏览器网络记录中没有远程书封／电影海报请求，卡片使用本地程序化视觉；周报只依据本机记录生成且无登录／上传要求；医学文字、来源、警示边界与插图替代文本可读。插图用于主题导航，不得被描述成诊断图或个体化治疗建议。

没有安装按钮不等于网页失败；但“添加到主屏”子项没有真正执行时不能记为通过。

## 同源缓存更新追加测试

此测试只需在至少一台 Android Chrome 和一台 iPhone Safari 上执行，但必须使用同一个 HTTPS Origin 的 A、B 两次部署。若临时账号过期导致 URL 改变，这一轮记为 `BLOCKED — ORIGIN CHANGED`，不能声称验证了更新。

1. 在最终 Origin 发布 A=`v2.3.0-r5`，打开并准备轻量离线，记录静态 ZIP SHA-256、在线 `sw.js` 的 SHA-256、页面当前条目、收藏和一项偏好。
2. 在同一个 Origin 发布通过独立审查的 B=`v2.3.1-r4`；不要清站点数据。关闭同源其他标签页后重新打开。
3. 等待“应用更新并重新载入”，由用户点击后切换；确认 B 的应用壳完整生效，无 A/B 混合文件。
4. 断网重开，验证 B 的轻量壳；若 A 曾下载完整离线包，分别核对壳、内容、医学图、搜索和音频的版本。版本未变的已验证包应复用，版本变化的包必须重新核验或下载，不能按整站版本粗暴清空，也不能静默复用不匹配内容。

通过标准：B 必要壳文件全部到齐后才可切换；失败的 B 安装不破坏 A；切换成功后旧应用 Cache 被清理，本地收藏／偏好／备份数据仍保留。
