## 每格步骤

1. 打开冻结发布地址和诊断页，记录完整 URL、浏览器版本、网络类型、时间与截图。
2. 确认版本 `v2.4.3`、Service Worker 受控、关键文件通过；首页若首次更新，按提示重载并完全关闭浏览器后再开。
3. 分别对书、电影、城市连续点击“下一个”至少 5 次：文字与图片属于同一 ID，图片解码后一次切入，不保留上一项，不按固定顺序递增，无横向裁切。
4. 滚动到德语和医学；播放一次女生朗读，检查停止／故障文案；打开收藏、偏好、轻量离线并完全关闭重开，确认数据保留。
5. 完成轻量离线后开启飞行模式并重开同一 Origin；记录首页壳与已缓存内容是否可用。
6. 关闭飞行模式，切换另一网络，重复第 2–5 步。

## Android／iPhone 同源 A→B

- A 为当前线上稳定版，B 为 v2.4.3；必须是同一个 Origin 和 scope。
- A 中写入收藏、偏好、探索记录和轻量离线；部署 B 后重开并按更新提示完成接管。
- B 必须保留 A 的个人数据，版本和缓存更新到 B，旧壳不与新内容混用；离线重开后再次检查。
- Android：`NOT_RUN`。iPhone：`BLOCKED — 无设备`。

## 判定

- `PASS`：该格全部步骤完成且有版本、网络、URL、截图或诊断摘要。
- `PASS — 用户真机确认`：用户明确确认该格全部功能步骤通过，但尚未提供浏览器版本或截图；不得改写为自动采集证据。
- `FAIL`：功能、数据、图片身份、布局、更新或离线行为不符合上述标准。
- `BLOCKED`：设备、网络或平台不可用；必须写明原因，不得改写为 PASS。
- 异常时先保存诊断摘要，不要先清除站点数据；清除会删除该 Origin 的本地收藏和偏好。
