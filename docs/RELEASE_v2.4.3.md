# 今日万象 v2.4.3 发布说明

状态：候选构建中；部署与实体设备验收尚未执行。

## 目标

v2.4.3 在 v2.4.2 可靠性收口之上只处理弱网和首屏性能，不改变 2,200 项候选池、每日策展逻辑、收藏／偏好／探索记录 schema 或备份语义。

## 变更

- 正常模式把 4 个基础模块和 10 个功能模块分别构建为 `runtime-foundation.js`、`runtime-features.js`，安全模式仍可逐模块回退。
- GitHub Pages 的不可变目录分片在同源请求超过 1.8 秒时启动固定提交 CDN 竞速；只有字节数和 SHA-256 均通过的响应可胜出，外部取消会终止两路。
- 书封、海报和城市图解码完成后才原子显示；旧代图片无法覆盖新项目。
- 同一第三方图片主机连续失败两次后在当前会话熔断 60 秒；同源城市图不参与熔断。
- 200 张已复核城市图增加 480×270 同源衍生图及逐文件来源哈希，移动端／弱网优先使用；宽屏保留 960×540 图。
- 诊断页显示最近一次首页 `routing / engine / catalog / modules / app` 等阶段耗时，不记录收藏、偏好、搜索词或 User-Agent。
- 新增受控弱网浏览器门禁，检查启动 JS 请求数、可操作首屏、随机换项、图片身份、解码后显示和 390 px 裁切。

## 发布边界

- `PASS` 只能来自当前工作树或最终 ZIP 干净解压后的真实命令记录。
- Playwright 的 Android UA 和移动视口是自动化兼容回归，不是夸克、vivo 浏览器或微信真机证据。
- v2.4.2 已冻结标签和发布包保持不变；v2.4.3 使用独立版本、ZIP、哈希和审查 sidecar。
- 本说明不授权部署。GitHub Pages、Cloudflare Pages 或 Worker 上传必须在用户确认目标 Origin、目标平台、发布版本和“现在部署”后执行。

## 候选验收

1. `npm test` 全量退出码为 0。
2. `npm run test:e2e:v243` 在受控弱网下通过并输出阶段耗时、请求数和图片换项证据。
3. 完整审计 ZIP 与精简静态 ZIP 均通过各自自校验。
4. 在完整审计 ZIP 的干净解压目录执行 `npm ci` 和全量测试。
5. 同一独立审查者从六个维度运行复核；修复后由其重新验证直至确认通过。
6. 部署后再执行 `docs/REAL_DEVICE_MATRIX_v2.4.3.md`；未执行格不得写为 PASS。
