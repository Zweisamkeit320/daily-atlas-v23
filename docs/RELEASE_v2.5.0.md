# 今日万象 v2.5.0 LTS 发布说明

状态：`LOCAL_CANDIDATE`。生产 v2.4.4 保持不变，直到本候选的自动化、精确封包、独立六维审查和同源 A→B 全部形成证据。

## 本版目标

v2.5.0 把已经完成真机与稳定观察的功能固化为最终功能基线，不新增候选、不改推荐算法、不迁移用户数据。新增的都是发布与长期维护边界：

- 公开配置和诊断摘要明确显示 `LTS 最终功能版` 与“功能冻结，仅维护修复”；
- 增加随源码包和静态包发布的 `LICENSE.txt` 与 `NOTICE.txt`；
- 公开安全素材模式固定为书影本地编辑视觉；公开目录移除第三方电影数值评分和票数，规范化图片地址只保留为不执行的条目身份完整性记录；
- 医学高风险自动筛查重新绑定 v2.5.0 当前内容文件和当前哈希；
- 固定最终功能范围、允许的 v2.5.x 补丁类型和停止无休止升级的规则；
- 以 v2.4.4 作为同一 Origin A→B 的正式基线。

## 不变合同

- 2,200 项内容及五池数量不变；不把版本更新伪装成内容扩充。
- 收藏、喜欢、不适合、偏好、探索记录、提醒、音频设置与离线状态的存储键和 schema 不变。
- 备份 JSON／加密备份格式不变，旧数据不需要迁移。
- 公开配置不请求或复制第三方书封／海报；书影统一使用本地编辑视觉。相关旧版渐进能力不会在未重新取得许可和审查时开启。
- 电影构建侧证据仍承担编辑质量门槛核验，但 IMDb 数值评分和票数不进入公开运行目录、搜索分片或静态部署包。
- 城市图继续逐项保留 Commons 来源、作者、许可和哈希；医学图与德语音频继续同源提供。
- 医学内容仍是一般健康教育，不提供诊断、处方、急救替代或个体治疗。

## 发布门槛

1. 完整 `npm test`、三引擎、双基址、弱网、离线、更新、持久化与 WCAG 测试通过；
2. 完整审计 ZIP 与精简静态 ZIP 分别生成，从干净目录复验且哈希一致；
3. 同一独立严格审查者从需求、逻辑、边界、质量、覆盖和真实运行六方面只读复核；
4. 部署前保留 v2.4.4 的收藏、偏好和离线状态，部署后验证 v2.5.0 同源 A→B；
5. Android Chrome 与 iPhone Safari 若仍无设备，保持 `BLOCKED`，不以模拟器冒充真机。

包内文档只记录封包前状态；精确 ZIP 哈希、干净解压、独立审查和最终部署结果写入包外证据侧车，避免修改已经被验证的文件。
