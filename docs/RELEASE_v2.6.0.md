## 本版唯一功能变化

500 本图书和 500 部电影采用“原图优先、原创插画回退”的统一视觉链。条目已有的 Open Library 书封或 MetaHub 电影海报默认以 network-only 方式渐进加载，完成解码且仍属于当前稳定 ID 后覆盖显示；无地址、404、超时、解码失败、离线、数据节省或显式安全模式均使用确定性原创 SVG 主题插画。历史、悬疑和科幻分别使用档案／通道／地形、迷宫／门槛／证据、轨道／信号／地平线等视觉母题；同一条目跨首页、详情和探索页保持同一视觉签名。

## 保持不变

- 五类候选池、轻音乐库、推荐逻辑和稳定 ID 不变。
- 第三方书封或电影海报不复制进发布包、不写入应用 Cache、不进入轻量／完整离线包；失败路径始终同源可用。
- 城市开放许可实图和医学主题图不变。
- 备份 JSON／加密备份格式不变，用户数据键和跨标签事务逻辑不变。
- 轻量／完整离线清单不增加 1,000 张位图；插画代码随应用壳缓存。
- 医学内容字节未改，继续继承绑定同一 `medical500.json` SHA-256 的 v2.5.0 自动筛查与独立内容审查证据，不声称重新取得医生签字。

## 验收目标

- 1,000 项均有确定性、唯一后备视觉签名，重复生成结果一致；当前目录的 1,000 项均有白名单原图候选。
- SVG 无外链、脚本、图片元素、事件属性或作品标题；单幅标记小于 6 KB。
- 首页、详情占位、探索页均保留插画底层；原图成功时覆盖显示，失败时露出插画。连续换书／电影时图文、图片候选与视觉签名一致。
- 320、360、390、428、768 px 无横向裁切；高对比、大字号、紧凑和减少动画路径可用。
- 三浏览器引擎、弱网、Service Worker 接管、轻量离线和断网重开回归通过。
- 静态包与完整审计包在干净目录重新安装依赖并验证后，才可提交部署确认。
