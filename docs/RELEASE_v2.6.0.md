# 今日万象 v2.6.0 LTS Visual Edition 发布记录

状态：`CANDIDATE — 自动验证进行中，尚未部署生产`  
版本日期：2026-09-03

## 本版唯一功能变化

500 本图书和 500 部电影的本地色块编辑视觉升级为确定性原创 SVG 主题插画。历史、悬疑和科幻分别使用档案／通道／地形、迷宫／门槛／证据、轨道／信号／地平线等视觉母题；书籍增加页框语言，电影增加分格语言。配色和微型几何细节由 `type + 稳定作品 ID` 决定，同一条目跨首页、详情和探索页保持同一视觉签名。

## 保持不变

- 五类候选池、轻音乐库、推荐逻辑和稳定 ID 不变。
- 公开配置仍不请求、不缓存、不复制第三方书封或电影海报。
- 城市开放许可实图和医学主题图不变。
- 备份 JSON／加密备份格式不变，用户数据键和跨标签事务逻辑不变。
- 轻量／完整离线清单不增加 1,000 张位图；插画代码随应用壳缓存。
- 医学内容字节未改，继续继承绑定同一 `medical500.json` SHA-256 的 v2.5.0 自动筛查与独立内容审查证据，不声称重新取得医生签字。

## 验收目标

- 1,000 项均有确定性、唯一视觉签名，重复生成结果一致。
- SVG 无外链、脚本、图片元素、事件属性或作品标题；单幅标记小于 6 KB。
- 首页、详情占位、探索页均显示插画；连续换书／电影时图文与视觉签名一致。
- 320、360、390、428、768 px 无横向裁切；高对比、大字号、紧凑和减少动画路径可用。
- 三浏览器引擎、弱网、Service Worker 接管、轻量离线和断网重开回归通过。
- 静态包与完整审计包在干净目录重新安装依赖并验证后，才可提交部署确认。
