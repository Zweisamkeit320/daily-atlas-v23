PRIVACY · LOCAL FIRST

隐私说明

今日万象 v2.6.0 LTS Visual Edition 是无账号、无后端的本地优先网页应用。本说明描述应用实际保存什么、何时会访问网络，以及用户如何导出或删除数据。

视觉请求可以关闭

v2.6.0 LTS Visual Edition 的公开安全素材模式默认以按稳定作品 ID 生成的原创本地主题插画呈现书与电影，不复制、不模仿也不向第三方图片服务请求书封或海报；城市使用已复核开放许可的同源图片。开启“数据节省模式”或安全模式后，城市也回到本地编辑视觉；只有用户随后明确选择“完整离线”时，才会批量请求并核验 200 张同源城市图。

一、我们不建立什么

没有账号没有注册、登录、手机号或社交账号绑定。
没有行为分析没有随包分析 SDK、广告追踪器或跨站用户标识。
没有健康画像上传医学主题偏好只影响本机选题，不上传，也不用于诊断。
没有云同步跨设备迁移依靠用户主动导出和导入 JSON 备份。

二、保存在当前设备的数据

  • 每日推荐状态、主动标记的探索记录、喜欢、不适合和收藏。
  • 书影题材、城市地区、德语等级和医学主题等显式偏好。
  • 外观、紧凑模式、音乐、朗读后备音色、提醒时间与离线范围。
  • PWA 应用壳、紧凑目录、已访问详情、医学插图、按需视觉缓存，以及用户选择安装的离线音频和 200 张开放许可城市图。
  • 最多 20 条不含错误正文的运行错误码：时间、阶段和错误代码。

这些数据位于浏览器的 localStorage、IndexedDB 或 Cache Storage。更换浏览器、清除站点数据或更换 Origin 后不会自动迁移。

三、可能发生的网络请求

  • 应用首次打开、更新、搜索或安装离线包时，从当前 Origin 下载程序、内容分片、医学图和德语音频；已知 GitHub QA Origin 的首次未受控页面可能尝试固定 jsDelivr 内容锚点，失败后回到同源。
  • 只有用户点击城市实时信息时，才会访问 Open-Meteo；请求包含城市坐标和查询时间，不包含收藏或个人画像。
  • 用户主动打开“查看来源”或说明页中的外部链接时，会离开本站；目标网站会按其自身隐私政策处理网络信息。
  • 当前公开配置不会向 images.weserv.nl、covers.openlibrary.org 或 images.metahub.space 请求书封／海报，因而不会通过图片 URL 泄露当前展示的书影作品 ID。用户点击作品资料或来源链接时会离开本应用并直接访问相应第三方站点，由该站点按自身隐私政策处理请求。
  • 城市风貌图只从当前 Origin 的 ./assets/visuals/cities/ 读取逐项核对开放许可的文件；不合格或缺失的城市继续显示程序化视觉。
  • 开启数据节省模式或安全模式后，日常卡片和探索页不请求远程书封、电影海报或城市风貌图；本地医学主题图仍保留。用户主动启动完整离线下载是明确例外，会请求 200 张同源城市图。

Service Worker 最多保留 180 项按需访问的同源城市图；公开版不建立书封或电影海报缓存。开启数据节省会停止日常浏览中的城市图片请求；“修复应用缓存”会清除应用管理的同源城市图缓存并重新校验离线包，但不会删除收藏、偏好或探索记录。

网络服务通常能够看到 IP 地址、时间、浏览器网络请求头等技术信息。本站设置 Referrer-Policy: no-referrer，尽量不把当前页面地址发送给外部站点。

四、备份、通知与删除

备份

备份只在用户点击后生成。可选密码加密使用 PBKDF2-SHA-256 与 AES-256-GCM，密码和派生密钥不保存、不上传。备份可能反映阅读、观看和健康关注偏好，应由用户自行妥善保管。

通知

应用只在用户主动启用提醒后请求浏览器通知权限。ICS 文件由用户主动导出，后续提醒由系统日历负责。

删除

用户可以在设置中重置偏好、清除浏览器站点数据，或使用诊断页只修复应用缓存。缓存修复会清除可重建的应用缓存（包括应用管理的按需同源城市图缓存）并重新校验已下载的完整离线内容，不会删除收藏、偏好和探索记录；完成后重新载入页面。清除整个站点数据前应先导出备份。

五、双入口与浏览器存储

夸克优先入口 zweisamkeit320.github.io/daily-atlas-v23/ 与 Cloudflare 备用入口 daily-atlas-mobile-cn.pages.dev 是不同 Origin，浏览器依法把它们的本地数据隔离。夸克、vivo 和微信内置浏览器即使打开同一地址，也各自使用独立存储。

因此，在另一入口或另一浏览器看不到收藏，不表示原数据被删除；原数据仍留在原浏览器和原地址。需要迁移时，请先在原入口导出 JSON，再到新入口查看变更预览并选择“合并”或“替换”。确认新入口数据完整前，不要清除原入口的网站数据。

应用不会自动跳转、跨 Origin 探测、通过 URL 搬运个人状态，也不会伪装成两个入口已经同步。两个 Origin 安装到桌面后也是两个独立 PWA。
