来源与许可边界

本页把“内容经过筛选”与“获得商业再分发授权”分开。评分、书目、图片、音频和医学资料的来源并不具有同一许可条件。

这不是一份商业授权证明

v2.4 以远程引用方式展示书封和电影海报，并为每张卡保留本地程序化回退；这不等于获得逐图商业再分发授权。城市图只有在逐项确认开放许可、作者和文件页后才进入同源发布包。正式商业运营仍须另行取得书影素材授权或替换受限数据。

图书

图书使用 Open Library Work 稳定 ID、书目字段和冻结评分快照进行候选筛选。Open Library 不对数据库材料主张新增版权，但说明部分贡献在不同司法辖区仍可能存在既有权利问题；书封许可也应与书目数据分开判断。

电影

电影评分和票数来自 IMDb 非商业数据集的冻结快照。IMDb 将该数据集限定为个人与非商业用途。当前公开候选只作非商业测试；商业运营前必须取得适用许可，或替换／移除相关数据。

  • IMDb Non-Commercial Datasets
  • IMDb Conditions of Use

封面与海报

封面、海报与元数据具有不同的许可边界。v2.4 的书封由 Open Library 作品／封面 ID 定位，电影海报由 IMDb ID 定位至 MetaHub 图片服务；运行时优先通过 images.weserv.nl 请求压缩 WebP，并保留原始服务回退。Open Library 的封面地址可能跳转至其 Internet Archive 后端 archive.org 及受控的 us.archive.org 存储子域；应用只接受从已核对的 covers.openlibrary.org 候选产生的跳转，不直接构造任意 Archive 候选。代理和跳转只改善传输，不授予图片版权。

这 1,000 项只作为远程引用，不在构建时批量下载，也不进入完整离线包。每张图均可失败关闭并露出本地程序化视觉；数据节省或安全模式下零请求。书影逐图商业再分发权尚未建立，本公开版本只定位为个人、非商业测试。

城市风貌图

城市图从 Wikimedia Commons 文件页发现，只有主题确实对应城市、作者署名完整，并使用 Public Domain、CC0、CC BY 或 CC BY-SA 的文件才会转换为同源 WebP。每项审计记录保留 Commons文件页、作者、许可名称和链接、检索时间、尺寸、文件 SHA-256；任何缺项都继续使用程序化城市视觉。

书影“图源”通向本页的封面与海报说明；城市卡片的“图源”会直达对应 Commons 文件页。查看 200 张城市图的可读署名与许可清单；机器可读清单也随静态发布包提供。开放许可仅覆盖相应城市文件，不延伸到书封、电影海报、评分或其他内容。

豆瓣

本版没有抓取、复制或显示豆瓣评分、评价人数或条目数据。只有获得书面许可和稳定接口后，才适合按来源、分数、人数和快照日期并列展示；不同平台评分不会混算成一个虚假综合分。

500 条德语朗读使用固定 Piper de_DE-eva_k-x_low 模型生成。模型、配置、文本与 MP3 哈希记录在随包 manifest，M-AILABS 许可通知随静态包提供。固定输入支持重建审计，但不保证两次编码得到字节完全相同的 MP3。

医学科普

医学内容来源限定为 WHO、CDC、NHS、NIH 下属机构、FDA、MedlinePlus、USPSTF、政府公共卫生机构和具有明确急救教育职责的机构。内容只作一般健康教育，不诊断、不替代医生、药师、急救或毒物咨询服务。

500 条内容按风险分为一般、需谨慎和紧急警示；v2.4 对全部 347 条 caution／urgent 内容执行结构安全筛查，并对本轮高风险问题逐条核对来源、警示措辞和行动边界。它仍是一般健康教育，不是医生签名、诊断或个体化治疗建议。
