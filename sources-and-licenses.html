来源与许可边界

本页把“内容经过筛选”与“获得商业再分发授权”分开。评分、书目、图片、音频和医学资料的来源并不具有同一许可条件。

这不是一份商业授权证明

v2.6.0 LTS Visual Edition 的公开配置不请求或复制第三方书封和电影海报，书影使用原创本地主题插画；城市图只有在逐项确认开放许可、作者和文件页后才进入同源发布包。构建侧来源审计不等于商业授权，正式商业运营仍须逐项核对内容和元数据的适用权利。

图书

图书使用 Open Library Work 稳定 ID、书目字段和冻结评分快照进行候选筛选。Open Library 不对数据库材料主张新增版权，但说明部分贡献在不同司法辖区仍可能存在既有权利问题；书封许可也应与书目数据分开判断。

  • Open Library Licensing
  • Open Library API 与使用规范

电影

电影候选在构建阶段使用冻结的来源证据完成编辑筛选，但公开运行目录、搜索分片和静态部署包不分发 IMDb 数值评分或票数。IMDb 官方帮助页把免费数据集限定在个人、非商业用途，并限制把它改造为在线或离线电影信息数据库；因此这些数值只留在不发布的构建审计输入，不能被公开页面或离线包调用。

  • IMDb Non-Commercial Datasets
  • IMDb 数据使用说明

封面与海报

封面、海报与元数据具有不同的许可边界。以作品 ID 定位图片、通过代理压缩或从图片服务获取成功，都不自动授予展示、衍生或再分发权。MetaHub 的官方条款也明确说明，其服务许可并不授予图片或海报本身的权利。

因此 v2.6.0 的公开配置不会请求 covers.openlibrary.org、images.metahub.space 或 images.weserv.nl 的书影图片，也不把任何书封／海报图片字节放入应用壳、运行时缓存或完整离线包。500 本书和 500 部电影均使用由作品类型、题材和稳定 ID 确定生成的原创本地 SVG 主题插画；插画不嵌入作品标题，不复刻人物、Logo、原封面或原海报构图。为核对旧版同源 A→B 的条目身份和防止路由被静默改写，目录与视觉清单仍保留不执行的规范化图片地址；remoteBookMovieImages: false 是公开发布硬门禁，浏览器不会把这些地址放入图片元素或发出请求。

MetaHub Terms of Use

同源缩略图准入规则：只有逐项记录作品 ID、原始文件页、权利人或作者、明确允许再分发及必要衍生处理的许可、许可链接、检索日期、文件 SHA-256 和转换说明后，图片才可以进入同源包。v2.6.0 LTS Visual Edition 没有把任何书封或海报声明为已满足这套条件，因此不会擅自复制第三方图片。

卡片上的图片来源状态

  • 同源开放许可图片：文件随应用发布，已保留逐项署名、许可和哈希，当前用于城市风貌图。
  • 第三方渐进图片：旧版曾支持、当前公开配置已停用的能力；若未来恢复，必须先建立适用许可并重新通过发布审查。
  • 原创本地主题插画：由应用以作品类型、题材和稳定 ID 确定生成的几何叙事 SVG，不含原书封、原电影海报、演员肖像或城市实景；无需网络并随应用壳离线可用。

当前书影卡片、详情预览和探索结果显示“本地编辑视觉 · 原创主题插画”，城市显示“同源开放许可图片”或失败后的本地回退；换项不会继续保留上一条目的图片或图源说明。

城市风貌图

城市图从 Wikimedia Commons 文件页发现，只有主题确实对应城市、作者署名完整，并使用 Public Domain、CC0、CC BY 或 CC BY-SA 的文件才会转换为同源 WebP。每项审计记录保留 Commons文件页、作者、许可名称和链接、检索时间、尺寸、文件 SHA-256；任何缺项都继续使用程序化城市视觉。

书影“图源”通向本页的本地编辑视觉与许可说明；城市卡片的“图源”会直达对应 Commons 文件页。查看 200 张城市图的可读署名与许可清单；机器可读清单也随静态发布包提供。开放许可仅覆盖相应城市文件，不延伸到书封、电影海报、评分或其他内容。

豆瓣

本版没有抓取、复制或显示豆瓣评分、评价人数或条目数据。只有获得书面许可和稳定接口后，才适合按来源、分数、人数和快照日期并列展示；不同平台评分不会混算成一个虚假综合分。

德语朗读与音乐

500 条德语朗读使用固定 Piper de_DE-eva_k-x_low 模型生成。模型、配置、文本与 MP3 哈希记录在随包 manifest，M-AILABS 许可通知随静态包提供。固定输入支持重建审计，但不保证两次编码得到字节完全相同的 MP3。

查看随包 M-AILABS 许可通知

背景轻音乐由浏览器实时合成；经典改编只使用公版作品并由项目重新编配，不包含商业录音或采样。

医学科普

医学内容来源限定为 WHO、CDC、NHS、NIH 下属机构、FDA、MedlinePlus、USPSTF、政府公共卫生机构和具有明确急救教育职责的机构。内容只作一般健康教育，不诊断、不替代医生、药师、急救或毒物咨询服务。

500 条内容按风险分为一般、需谨慎和紧急警示；v2.5.0 对全部 500 条执行绑定当前内容文件与哈希的结构安全筛查，对其中 347 条 caution／urgent 高风险子集重点统计，并由独立内容审查核对紧急、用药、孕产与心理危机等主题的来源、警示措辞和行动边界。它仍是一般健康教育，不是医生签名、诊断或个体化治疗建议。
